## 1. Relever le NUP

Le NUP compte 9 chiffres. Il figure sur l'attestation, le certificat ou le titre que vous montre le vendeur. Saisissez-le sur la [page d'accueil](/) ou dans [Vérifier](/recherche).

Pas de NUP ? Vérifiez avec le [levé du géomètre](/leve) que vous remet le vendeur.

## 2. Regarder le terrain

Chaque fiche montre l'emprise de la parcelle sur les images satellite annuelles. Un vendeur peut produire un faux papier, pas une fausse image satellite : comparez les années pour voir ce qui a changé.

## 3. Lire le verdict

| Verdict | Ce qu'il signifie |
|---|---|
| **Rouge** | N'achetez pas. Terrain de l'État, litige déclaré, ou vendeur qui n'est pas le titulaire. |
| **Orange** | Propriété pas encore confirmée ou information manquante : vérifiez avant de payer. |
| **Vert** | Titre foncier au nom du vendeur, aucun litige ni alerte connus. |

Ouvrez « Pourquoi ce verdict ? » : chaque signal est expliqué, avec ce qu'il faut faire pour lever le doute.
